1. O que é IA?

Inteligência Artificial é uma tecnologia que permite aos computadores realizar tarefas que normalmente precisam da inteligência humana, como aprender, reconhecer imagens e resolver problemas.

IA estreita: realiza tarefas específicas, como assistentes virtuais e tradutores.

IA geral: seria capaz de realizar diferentes tarefas intelectuais de maneira semelhante aos seres humanos.

Teste de Turing: criado em 1950 por Alan Turing, verifica se uma máquina consegue conversar de maneira semelhante a uma pessoa.

Conferência de Dartmouth: aconteceu em 1956 e marcou o início da IA como área de pesquisa científica.

Fontes: Stanford Encyclopedia of Philosophy; IBM.

2. Aprendizado de máquina

Machine Learning é uma área da IA em que os computadores aprendem padrões utilizando dados.

Supervisionado: aprende com exemplos que possuem respostas corretas. Exemplo: identificar mensagens de spam.

Não supervisionado: encontra padrões sem respostas prontas. Exemplo: agrupar clientes por hábitos de compra.

Por reforço: aprende por tentativas, recompensas e penalidades. Exemplo: aprender a jogar videogame.

Fontes: IBM; Google Machine Learning Crash Course.

3. Redes neurais

Um neurônio artificial é uma unidade matemática que recebe informações e realiza cálculos.

  • Entradas: informações recebidas.
  • Pesos: importância de cada informação.
  • Bias: valor utilizado para ajustar o resultado.
  • Função de ativação: determina o resultado transmitido adiante.

Deep Learning é uma técnica que utiliza redes neurais com várias camadas para aprender padrões complexos.

A IA é o conjunto maior. Dentro dela existe o Machine Learning e dentro do Machine Learning existe o Deep Learning.

Fontes: IBM — Neural Networks; IBM — Deep Learning.

4. Dados

Os dados de treinamento são importantes porque permitem que a IA aprenda padrões e produza resultados.

Dados de treino: utilizados para ensinar o modelo.

Dados de teste: utilizados para verificar se o modelo funciona com informações novas.

Overfitting: acontece quando o modelo memoriza os dados de treinamento e tem dificuldade com dados diferentes.

Garbage in, garbage out: significa que dados ruins produzem resultados ruins.

Fontes: Google Machine Learning Glossary; IBM.

5. IA generativa

IA generativa é uma tecnologia capaz de criar textos, imagens, músicas e códigos.

LLM é um grande modelo de linguagem treinado com muitos textos para compreender e gerar linguagem humana.

Token: é uma unidade de texto que pode representar uma palavra ou parte dela.

O LLM gera textos prevendo o próximo token e repetindo esse processo até formar uma resposta.

Transformer: arquitetura apresentada em 2017 que utiliza mecanismos de atenção para compreender relações entre palavras e partes de um texto.

Fontes: Attention Is All You Need (2017); IBM.

6. Limitações

Alucinação de IA acontece quando a inteligência artificial apresenta informações falsas como se fossem verdadeiras.

Isso ocorre porque o modelo prevê palavras e pode produzir informações sem verificar se são reais.

Para verificar uma resposta, devemos consultar fontes confiáveis, comparar informações e conferir se os estudos citados existem.

Data de corte: é a data limite aproximada das informações utilizadas no treinamento do modelo.

Fontes: Google Cloud; OpenAI.

7. Ética e viés

Viés algorítmico acontece quando um sistema de IA apresenta resultados injustos para determinados grupos de pessoas.

Um caso real foi identificado em pesquisas sobre reconhecimento facial realizadas pelo NIST, nos Estados Unidos. Os estudos encontraram diferenças nas taxas de erro conforme características como raça, idade e sexo.

Uma das causas é a utilização de dados de treinamento pouco variados, que não representam igualmente todos os grupos.

Fontes: NIST — Face Recognition Technology Evaluation.

8. Regulação

O AI Act é uma legislação da União Europeia que classifica sistemas de IA conforme seus níveis de risco.

  • Risco inaceitável: práticas proibidas.
  • Alto risco: precisam seguir regras rigorosas.
  • Risco limitado: exigem transparência.
  • Risco mínimo: possuem poucas obrigações.

O PL 2338/2023 é um projeto brasileiro que busca regulamentar a inteligência artificial. Sua tramitação deve ser consultada na Câmara dos Deputados para verificar a situação atual.

O artigo 20 da LGPD permite que uma pessoa solicite a revisão de decisões tomadas exclusivamente por sistemas automatizados que afetem seus interesses.

Fontes: União Europeia — AI Act; Câmara dos Deputados — PL 2338/2023; LGPD.

9. Usando IA no código

Engenharia de prompt é a técnica de criar instruções para conseguir respostas melhores de uma IA.

Três técnicas são:

  1. Dar contexto para explicar o problema.
  2. Mostrar exemplos de respostas esperadas.
  3. Definir o formato da resposta.

Uma API permite que um aplicativo se comunique com um serviço de inteligência artificial.

Chave de API: código secreto que permite acessar o serviço.

Cobrança: geralmente ocorre conforme a quantidade de tokens enviados e recebidos.

A chave nunca deve ficar no front-end porque pode ser extraída por outras pessoas. Ela deve ficar protegida no back-end.

Fontes: OpenAI API Documentation; OpenAI API Key Safety.

10. Interpretação de texto

a) Qual limitação explica a dose errada?

A limitação é chamada de alucinação de IA. O sistema inventou informações porque tentou produzir uma resposta provável sem verificar se os dados eram verdadeiros.

b) Por que gravar a chave da API foi uma falha?

Porque outras pessoas poderiam extrair a chave e utilizá-la sem autorização. Ela deveria ficar protegida em um servidor back-end.

c) Qual foi o problema com os dados pessoais?

O aplicativo enviava informações pessoais sem explicar adequadamente o tratamento aos usuários. Isso contraria princípios da LGPD, como necessidade e transparência. Para responder às perguntas, geralmente bastariam a dúvida e as informações técnicas necessárias.

d) O que é human-in-the-loop?

É quando uma pessoa participa da revisão das respostas e decisões produzidas pela IA.

Dois exemplos de decisões que não devem ser tomadas somente pela IA são recomendar doses de defensivos agrícolas e decidir tratamentos médicos sem avaliação profissional.

e) Comente a frase de Bianca.

A frase significa que a IA pode ajudar muito, mas não é perfeita e pode cometer erros. Por isso, não devemos confiar em todas as respostas sem verificar.

Três cuidados importantes são:

  1. Verificar as respostas em fontes confiáveis.
  2. Guardar a chave da API no back-end.
  3. Proteger os dados pessoais e respeitar a LGPD.

Fontes: OpenAI API Documentation; LGPD; ANPD.
